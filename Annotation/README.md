# Annotation

This folder contains the annotation materials for the project **Detecting Sarcasm in Code-Switched Turkish–English Fan Discourse**.

The annotation process asks annotators to classify Turkish–English code-switched replies using three primary labels:

- Sarcastic
- Non-sarcastic
- Ambiguous/Uncertain

For replies labeled **Ambiguous/Uncertain**, annotators will also identify the reason for their uncertainty. This additional annotation was introduced based on feedback received on the project proposal.

This folder will contain:

- **Guidelines/** – Detailed annotation instructions, label definitions, decision rules, and examples.
- **Interface/** – Configuration and instructions for the annotation interface.
- **Results/** – Annotation outputs collected from annotators.
